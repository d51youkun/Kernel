📲 インストール方法

KernelはApp Storeには公開されていません。サイドロード（非公式インストール）が必要です。

SideStore を使う方法（推奨）

1

SideStoreをインストール

sidestore.io からSideStoreをインストールしてください。初回のみMac/PCが必要です。

2

IPAをダウンロード

GitHub Releases から最新の Kernel.ipa をダウンロード

3

SideStoreでインストール

SideStoreを開き、「＋」ボタンからIPAファイルを選択してインストール

4

7日ごとの更新

SideStoreのVPNが有効な状態で自動更新されます。手動の場合は同じ手順を繰り返してください。

Sideloadlyを使う方法

ℹ️ Mac/PCにApple IDを登録する必要があります。7日ごとに再インストールが必要です。

1

Sideloadlyをインストール

sideloadly.io からダウンロード・インストール

2

iPadをUSB接続

Sideloadlyを起動し、IPAファイルをドラッグ。Apple IDを入力してStartをクリック

3

デバイスを信頼

設定 → 一般 → VPNとデバイス管理 → Apple ID → 信頼

🧠 GGUFモデルの追加方法

推奨： 初めて使う場合は Qwen2.5-3B-Instruct-Q4_K_M.gguf（約2GB）から始めましょう。日本語が得意で動作が軽快です。

モデルのダウンロード先

モデル名サイズ特徴推奨端末
Llama-3.2-1B-Instruct Q4_K_M~0.8GB最軽量・高速全機種
Qwen2.5-3B-Instruct Q4_K_M~2.0GB日本語強い・バランス良M1以上
Llama-3.2-3B-Instruct Q4_K_M~2.0GB英語が得意M1以上
Qwen2.5-7B-Instruct Q4_K_M~4.7GB高品質・日本語◎M2以上16GB
Qwen2.5-9B-Instruct Q4_K_M~5.6GB高品質・M4推奨M4 16GB以上

上記モデルは Hugging Face からダウンロードできます。検索に gguf q4_k_m と入力してください。

Kernelへの追加手順

1

GGUFファイルを用意

Hugging FaceからSafari経由でダウンロードするか、Macから転送します。

2

Files.appでKernelフォルダに配置

Files.app → このiPad内 → Kernel → Documents → Models にGGUFファイルを移動

3

Kernelで選択

アプリを起動 → 左上のモデル名をタップ → 追加したモデルを選択

または：左下のユーザーアイコン → 設定 → モデルセクション から追加ボタン（＋）をタップ

⚡ JIT有効化（内蔵デバッガ）

⚠️ 注意： JITは推論の高速化技術ですが、GGUFモデルの動作には必須ではありません。設定せずに普通に使えます。

JITとは？

JIT（Just-In-Time Compilation）は、コードを実行時にコンパイルして高速化する技術です。Kernelの場合、Metal GPUを使わないCPU推論時に速度が向上します。Metal ON（デフォルト）の場合はJITの効果は限定的です。

方法1：ペアリングファイル方式（推奨）

MacにiDevice Pairをインストールし、ペアリングファイルを生成してKernelに読み込む方法です。

Step 1: MacにHomebrewをインストール

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Step 2: iDevice Pairをインストール

brew install libimobiledevice

Step 3: iPadをUSBでMacに接続

ℹ️ iPadで「このコンピューターを信頼しますか？」が表示されたら「信頼」をタップしてください。

Step 4: ペアリングファイルを生成

idevice_pair pair

成功すると SUCCESS: Paired with device ... と表示されます。ペアリングファイルは以下の場所に保存されます：

/var/db/lockdown/[デバイスのUDID].plist

Step 5: ファイルをiPadに転送

1

ファイルをコピー

ls /var/db/lockdown/*.plist

表示されたファイルをAirDropまたはUSBでiPadに転送します。

2

Kernelにインポート

Kernel → 設定 → JIT・内蔵デバッガ → 「ペアリングファイルを追加」をタップ → plistファイルを選択

3

JITを有効化

「内蔵デバッガでJITを有効化」をタップ。「JIT実行確認済み」と表示されれば成功です。

方法2：StikJIT / StikDebug（VPN方式）

外部アプリのVPNを使う方法です。Kernelの設定画面からワンタップで呼び出せます。

1

StikJITまたはStikDebugをインストール

GitHub: StikDebug/StikJIT からIPAをダウンロードしてSideStoreでインストール

2

Wi-Fiに接続した状態でKernelを開く

LocalDevVPNが必要です。StikJITを起動してVPNを有効にしてください。

3

KernelからJITを有効化

設定 → JIT・内蔵デバッガ → 「内蔵デバッガでJITを有効化」

⚙️ 設定ガイド

推論設定

設定項目説明推奨値
Metal GPUを使用Apple SiliconeのGPUで推論を高速化ON（必須）
CPUスレッド数CPU推論時の並列スレッド数M4: 4コア
コンテキスト長一度に記憶できるトークン数4096
最大出力1回の返答の最大長1024
創造性（Temperature）0に近いほど正確、1.5に近いほど創造的0.65
メモリ警告大きいモデル読み込み時に警告表示9Bなら OFF

日本語・翻訳設定

英語で回答が返ってきた場合、生成中にリアルタイムで日本語に翻訳します。段落が確定するたびに即時置き換えるため、全文生成後を待つ必要はありません。

💡 ヒント： カスタム指示に「必ず日本語で回答してください」と入力すると、最初から日本語で生成されるため翻訳不要になり速度が上がります。

メモリ機能

設定 → 「メモリ（自分で登録した情報）」に任意のテキストを入力すると、すべての会話でその情報を参考にします。例：「私の名前は〇〇です。Swift開発者です。」

❓ よくある質問

Q. モデルが「メモリ不足」と表示される

A. 使用中の他のアプリを終了してからKernelを再起動してください。それでも解決しない場合は、より小さい量子化モデル（Q4_K_S または 3B以下）をお試しください。M4 iPad Pro（16GB）の場合は設定の「大きいモデルのメモリ警告」をOFFにすると9Bまで試せます。

Q. 回答が途中で止まる

A. 「最大出力トークン数」を増やしてください（設定 → 推論 → 最大出力 → 2048）。または新しいチャットを開いて再試行してください。

Q. 英語で回答が返ってくる

A. カスタム指示（設定 → カスタム指示）に「必ず日本語で回答してください」を追加してください。または日本語対応のInstructモデル（Qwen2.5シリーズ推奨）をお使いください。

Q. JITは必要ですか？

A. 必須ではありません。Metal GPU（設定でON）が有効な場合、JITによる速度向上は限定的です。CPU推論のみを使う場合に効果があります。

Q. 7日ごとにアプリが使えなくなる

A. 無料のApple IDでサイドロードした場合、7日ごとに再インストールが必要です。SideStoreを使うと自動更新されます。

Q. iPadからHugging Faceでモデルをダウンロードできますか？

A. はい。SafariでHugging Faceを開き、GGUFファイルのダウンロードリンクをタップするとFiles.appに保存されます。その後Files.app → Kernel → Documents → Models に移動してください。
